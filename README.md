#Project Description: ( By Huỳnh Lê Tâm Hiếu / ID: 107292 )

- This is a Flutter-based mobile application project developed for academic purposes at the UDA. The application facilitates connections between travelers and local guides, featuring trip management, payment processing, and profile customization

#To run this project locally, please follow these steps:

1.Run the Backend Server
- Open your terminal and navigate to the api directory within the source code: "cd api"
- Install dependencies: "npm install"
- Start the server: "npm start"
2.Run the Flutter Application
- Open a new terminal and navigate to the project root: "flutter pub get"
- run the app: "flutter run"
